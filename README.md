21 Number Game 🎮

A simple number game built with Python and Object-Oriented Programming (OOP).

About the Project

This project is a console-based game that uses object-oriented programming concepts to organize the game logic and manage the players.

Concepts Used

- Python
- Object-Oriented Programming (OOP)
- Classes and Objects
- Inheritance
- Random Module

Project Structure

The project uses separate classes to manage the players and the game logic.

How to Run

1. Install Python 3.
2. Clone this repository.
3. Run the main Python file.

Game.py

Replace "Game.py" with the actual filename if your entry-point file has a different name.
